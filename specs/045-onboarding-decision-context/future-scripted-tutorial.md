# Protected Follow-up: Authored Guided Championship Run

**Status**: Desired future onboarding; explicitly not Feature 045 V1  
**Source**: Owner clarification, 2026-08-17

The long-term tutorial should resemble The Bazaar's approach: take the player
through a complete authored run with a limited set of real item choices, tuned-
down opponents, and a deliberately achievable build payoff. It should teach the
game while letting the player experience the satisfaction of a coherent build
coming online and visibly “popping off.”

The future Specify/Clarify pass must decide:

- exact authored encounter/race count and duration;
- entrant/vehicle choice versus one tutorial entrant;
- which real items and mechanics are offered, and how choices remain meaningful
  while preventing an unrecoverable failed build;
- whether the player can lose, retry a race, or diverge from the intended build;
- tuned opponent builds/times, race spectacle, and final payoff moment;
- scripted versus seeded decisions and compatibility with future balance edits;
- completion rewards/unlocks, replay, skip, accessibility, persistence, and
  version migration;
- telemetry/comprehension evidence, if any, and privacy boundaries;
- how the guided run avoids mutating or masquerading as a normal championship.

Feature 045's deck architecture may supply copy, settings/replay entry, and
preference storage, but its implementation must not create a partial scripted
run or constrain this future design prematurely.

# Feature 045 How to Play Content Lock

**Deck version**: `how-to-play-v1`  
**Format**: Ten static, code-native slides with Next, Back, Skip/Exit, page
position, visual example, concise copy, and complete accessibility summary.

The deck explains current implemented mechanics. It does not simulate a run,
grant items, select an entrant, spend credits, generate a track, or expose Test
Day. All examples are projections from named deterministic fixtures and current
typed content; no slide derives mechanics from prose.

## Copy constraints

- Slide body: at most 55 words, excluding labels generated by authoritative
  presentation models.
- No slide says an item guarantees victory, a region has one correct build, or
  an unretained next race is known.
- No slide mentions Test Day, sandbox practice, or a player-facing practice
  route while Test Day visibility is disabled.
- Feature 041/042 slides fail compatibility with an honest unavailable state if
  their required typed data is absent; they do not show speculative mechanics.
- Every icon/shape has adjacent text and a complete ordered accessibility label.
